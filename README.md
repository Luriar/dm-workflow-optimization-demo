# 기존 Instagram DM 업무 프로그램 최적화

> 이 저장소는 실제 인턴 및 별도 프로젝트 경험을 설명하기 위해 새로 작성한 공개 포트폴리오입니다. 회사의 원본 소스, 데이터베이스, 고객 정보, 운영 설정, 인증정보를 포함하지 않습니다. demo.py와 예시 데이터는 2026년에 처음부터 작성한 독립적인 오프라인 재현 예제로, 2024년 실제 운영 코드를 복제하거나 당시 배포 사실을 증명하지 않습니다.

**공개용 데모:** 실무 경험을 바탕으로 2026년에 별도로 구현한 데모입니다. 회사 내부 자료와 원본 코드를 보호하기 위해 가상 데이터를 사용했으며, 2024년 실무 구현과 공개 데모의 검증 범위는 구분합니다.

**기간:** 인턴: 2024.07~09  
**실제 업무 기술:** Python, Selenium, MySQL, Kivy 기반 UI, 운영 로그

## 배경과 해결하려던 문제

기존 자동 발송 프로그램의 화면, 대상 데이터 관리, 실패 처리와 운영 편의성을 개선해야 했습니다.

## 직접 수행한 작업

- 기존 프로그램 구조를 분석하고 사용하지 않는 화면과 기능을 정리했습니다.
- Excel/파일 중심으로 다루던 대상과 메시지의 DB 연동 흐름을 개선했습니다.
- 발송 실패를 확인하고 예외에 대응할 수 있도록 기록과 운영 절차를 정리했습니다.
- 여러 PC에서 실행하고 인수인계할 수 있도록 환경 설정 및 작업 순서를 문서화했습니다.

## 기여 범위 및 사실 확인

최초 자동 DM 프로그램은 타인이 만든 기존 소프트웨어 및 오픈소스 기반이며, 본인은 이를 분석하고 최적화했습니다. 단독 신규 개발이라고 주장하지 않습니다.

## 공개 오프라인 데모

동의 여부, 중복, 제외 명단과 실패 상황을 확인하는 네트워크 없는 발송 계획 시뮬레이터입니다. 실제 메시지를 전송하지 않습니다.

```bash
python demo.py
python -m unittest discover -s tests -v
```

Python 3.10 이상을 권장합니다. 외부 API 키나 실서비스 계정이 필요하지 않습니다.

## 실행 가능한 확장 데모 (2026)

기존 개념 예제 `demo.py`와 별개로 `workflow.py`에 **SQLite 기반 영속 Outbox, 동의 검사, 중복 계획 방지, 재시도 상태 기계, 감사 로그**를 구현했습니다. 실제 메시지는 전송하지 않고 가상 Fake Transport만 사용합니다.

```bash
python workflow.py
python -m unittest discover -s tests -v
```

자세한 구조는 [워크플로 도식](docs/WORKFLOW.md)을 참고하세요. 이 데모의 기술 범위는 2024년 원본 프로그램의 구현 내용을 그대로 나타내지 않습니다.

## 재현 및 검증 범위

가상 발송 대기열에서 중복 등록, 동의 철회, 실패 재시도와 재시도 한도, SQLite 재접속 후 작업 보존을 검사합니다.
