# 공개용 워크플로 아키텍처

2024년 기존 Instagram DM 프로그램 최적화 경험을 설명하기 위해 2026년에 새로 구현한 독립적인 시뮬레이터입니다. 회사의 원본 동작, 테이블, 선택자 또는 내부 발송 정책을 복제하지 않습니다.

## 기능과 검증

- 중복 계획 요청에 같은 대상이 두 번 등록되지 않는 유일성 제약
- 실행 직전 동의 상태 재검증과 제외 대상 차단
- 재시도 상한, 지수형 대기, 실패 상태와 감사 이력
- SQLite 파일 재오픈 후에도 대기 작업 보존
- 실제 Instagram API, Selenium 및 네트워크 호출 **없음**
